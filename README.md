# Flask Review Lab 2

Учебное Flask-приложение для лабораторной работы № 2
«Ветвление и проверка изменений».

Проект разрабатывается командой из трёх человек с использованием
Git, GitHub, Pull Request и автоматических тестов.

## Требования

- Python 3.12
- Git
- Установленные зависимости из requirements.txt

## Установка (Windows CMD)

Создать и активировать виртуальное окружение:

```cmd
python -m venv .venv
.venv\Scripts\activate
```

Установить библиотеки:

```cmd
python -m pip install -r requirements.txt
```

## Запуск приложения

```cmd
python app.py
```

Открыть в браузере: http://127.0.0.1:8080

## Тестирование

```cmd
python -m pytest -q
```

## Доступные маршруты

- `/` — главная страница, возвращает Hello, World!
- `/about` — информация об учебном проекте.
- `/health` — проверка состояния приложения. Возвращает JSON `{"status":"ok"}`.

Маршрут /version находится в разработке и будет добавлен в следующем обновлении.
